# ⛏️ Minecraft Web 3D

> **创作者**：Aidan Gao  
> **作品定位**：Aidan Gao 的第一个编程作品（Project #1）  
> **详细开发日志**：请参阅 [`DEVLOG.md`](DEVLOG.md)

基于 **Three.js / WebGL** 构建的轻量级网页版 Minecraft 沙盒建造游戏。零额外图片资源依赖（程序化像素渲染）、即开即玩、内置自由飞行建造、完整建筑存档与导入导出功能，全面支持 iPad 触屏与免鼠标纯键盘独立游玩。

### 🌐 全球在线即玩（GitHub Pages）
无需下载任何软件或启动服务，直接点击在线游玩：  
👉 **https://sydneygemstone-sudo.github.io/aidan-minecraft-web/**

### 💻 本地局域网快速访问
- **本机电脑访问**：**`http://localhost:5173/`**
- **iPad / 手机 / 局域网其他电脑**：**`http://192.168.1.100:5173/`**（确保在同一 Wi-Fi）

### 启动服务脚本
在终端中进入项目目录执行：
```bash
./start.sh
# 或者运行局域网服务
npm run serve
```

| 操作分类 | 快捷按键 | 功能描述 |

## 📱 iPad 触屏操作方式

在 iPad 打开后，游戏会自动适配或可随时点击顶部「📱 触屏按键」呼出虚拟按键：
- **左侧虚拟十字键**：轻按 ▲ ▼ ◀ ▶ 控制前后左右移动。
- **右半侧屏幕滑动**：在屏幕右侧空白区域滑动手指，即可自然丝滑地旋转第一人称视角。
- **右侧快捷大按键**：
  - ⛏️ **挖掘**：长按或点按挖掘破坏方块
  - 🧱 **放置**：点按放置所选方块
  - 🕊️ **上升**：升空或跳跃
  - ⬇️ **下降**：降落
  - 🔄 **飞行**：随时开关飞行模式
  - 🎒 **库**：打开方块库
- **快捷栏**：直接用手指轻点底部方块栏即可秒切方块！

## ✨ 核心特色

1. **纯粹建造与自由飞行 (`F` 键)**：
   - 默认开启自由飞行模式，无重力约束，可在任意高度悬停、穿梭、俯瞰，随心所欲搭建空中楼阁。
   - 随时按 `F` 可切换回经典地面生存重力与碰撞检测。
2. **建筑存档与分享 (JSON 导入/导出)**：
   - **快速保存**：点击顶部「💾 保存」，游戏将整张地图的建筑记录持久化保存在浏览器本地（刷新不丢失）。
   - **导出存档**：点击「📂 导出存档」，即可将世界坐标与方块清单下载为标准的 `.json` 文件，方便备份与分享给好友。
   - **导入存档**：点击「📥 导入存档」，选择 `.json` 文件即刻无缝重建所有建筑。
3. **内置经典建筑奇观 (一键生成)**：
   - 🏰 **中世纪要塞城堡**：四座坚固防御塔楼、城墙垛口、中央主堡与荧石信标。
   - 🏡 **现代海景别墅**：极简现代铁块框架、全景通透玻璃幕墙、观景木平台与无边戏水池。
   - 🌳 **巨型空中树屋**：高耸入云的中空粗壮橡木干、繁茂树冠小屋与旋转木阶梯。
   - 🔺 **黄金法老金字塔**：阶梯式砂岩古迹，纯金与钻石顶尖信标，隐藏藏宝暗室。
4. **100% 纯自研程序化体素与音效**：
   - **像素材质生成器**：18+ 种方块材质全部由 HTML5 Canvas 程序化生成 16×16 经典像素艺术，采用 `THREE.NearestFilter` 渲染，永无模糊或图片加载失败。
   - **Web Audio API 拟真音效**：木头、石头、玻璃、草地、泥土各有专属的碎裂与放置音效，包含脚步声与飞行切换声。
   - **环境光照与 AO**：体素面消隐优化（Hidden Face Culling）与角落环境光遮蔽（Ambient Occlusion），帧率稳定 60~120 FPS。
5. **局域网物理分发引擎 (`server.js`)**：
   - 独立构建局域网 HTTP 分发服务器，彻底过滤屏蔽 Tailscale 虚拟网卡（`100.x.x.x`）干扰，确保真实物理 Wi-Fi 下其他电脑与 iPad 秒连秒开。
